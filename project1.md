

## 1. Website Status Checker (Internet + Automation)

**What this project is about:**
In this project, you write a Python script that checks whether a website is **UP (working)** or **DOWN (not responding)** by sending an HTTP request (a request your browser also sends when you open a site).

**Why this is fun:**
You feel like a mini-monitoring system because your script can tell you which websites are live and which are broken.

**What you will learn clearly:**
You will learn how HTTP works (HTTP means the protocol that browsers use to talk to websites), how status codes like `200`, `404`, and `500` work, and how to automate repetitive checks.

**Extra fun idea:**
You can make the script check multiple websites every 5 minutes and print alerts.

## 2. YouTube Video Downloader (Real Internet Power)

**What this project is about:**
You write a Python script that downloads YouTube videos or audio using a library like `pytube` or `yt-dlp`.

**Why this is fun:**
It feels powerful because your script controls content from the internet instead of you clicking buttons manually.

**What you will learn clearly:**
You will understand how URLs work, how streaming data is fetched, and how files are saved automatically on your system.

**Important practical thinking:**
You should only download videos for educational or personal use to stay ethical and legal.

## 3. Fake Login Page Detector (Cybersecurity-style Fun)

**What this project is about:**
Your Python script takes a website URL and checks basic things like HTTPS usage, suspicious domain names, and redirects.

**Why this is fun:**
It feels like **thinking like a hacker but acting like a defender**, which is actually more useful in real life.

**What you will learn clearly:**
You will learn what phishing is (phishing means tricking users into giving passwords), how SSL works (SSL means encrypted communication), and how attackers fool people.

**Extra fun idea:**
You can make the script give a “Risk Score” for a website.
