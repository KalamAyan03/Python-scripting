
Yahan kuch **Fun & "Khuraafaati" Python Projects** hain:

### 1. The "Annoying" WhatsApp Automator 📱

Yeh project doston ko prank karne ke liye best hai.

* **Kya karega:** Tum script se kisi dost ko 100 baar "Hello" bhej sakte ho, ya raat ke 12 baje automatic "Happy Birthday" wish schedule kar sakte ho bina jage.
* **Library:** `pywhatkit` aur `pyautogui`.
* **Learning:** Browser automation aur loop control seekhoge.
* **Fun Factor:** Dost ka phone vibrate hoke hang ho jayega!

### 2. WiFi Password Extractor (Saved WiFi Grabber) 📶

Yeh project tumhe asli "Hacker" feel dega, par yeh actually legal hai (apne system par).

* **Kya karega:** Tumhare laptop mein jitne bhi WiFi networks aaj tak connect hue hain, yeh script un sabke passwords nikaal kar ek text file mein save kar degi.
* **Library:** `subprocess` (Yeh Python ka built-in tool hai jo system commands chalata hai).
* **Learning:** Tum seekhoge ki Python se CMD commands kaise run karte hain aur output kaise filter (Regex) karte hain.

#### 3. Phone Number "Jasoos" (Tracker) 🕵️‍♂️

Cyber Intelligence ke liye yeh basic OSINT tool hai.

* **Kya karega:** Kisi bhi mobile number ko input karo, aur yeh script bata degi ki woh number kis country ka hai, kaunsa service provider (Jio, Airtel) hai, aur potential location (state) kya hai.
* **Library:** `phonenumbers`.
* **Learning:** APIs aur Data extraction samajh aa jayega.

#### 5. Invisible Keylogger (Educational Purpose Only) ⌨️

Yeh thoda advanced hai par Cyber Security student ke liye zaroori hai.

* **Kya karega:** Yeh script background mein chupchap chalegi aur user jo bhi type karega (passwords, chats), use ek text file mein record karegi.
* **Library:** `pynput`.
* **Warning:** Isse sirf apne system par test karna. Doosron pe use karna illegal hai.
* **Learning:** Background processes aur keyboard listening events.
